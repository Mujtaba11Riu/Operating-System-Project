# Operating-System-Project
This project is built entirely in pure Python — no web framework, no external server required.
The following libraries are used:
LibraryPurposetkinterBuilt-in Python library used to build the entire GUIrequestsFetches live CVE vulnerability data from the NIST NVD APIreportlabGenerates professional PDF security reportsPillowCreates the custom shield lock icon
Only 3 pip installs are required — tkinter comes pre-installed with Python and needs no separate installation.
bashpip install requests reportlab Pillow
